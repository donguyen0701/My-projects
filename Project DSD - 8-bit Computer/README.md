# 8-Bit Computer from Scratch (Role: Team Leader)

This repository documents one of my most meaningful university projects, developed for the **Digital System Design** course as part of my Electrical and Computer Engineering (ECE) studies at the **Vietnamese-German University (VGU)**.

## 🖥️ About the Project

Our team designed and physically assembled a fully functional **8-bit computer from the ground up**.

Before constructing the hardware, we designed, simulated, and tested the complete computer architecture using **Proteus Design Suite 8**. After verifying the individual modules and their interactions, we manually assembled the system using breadboards, discrete logic integrated circuits, EEPROMs, LEDs, and extensive point-to-point wiring.

The project combines theoretical computer architecture with practical digital-electronics design, system integration, testing, and hardware troubleshooting.

## 👥 My Contribution as Team Leader

As the team leader, I was responsible for:

* Coordinating the overall architecture and development process.
* Dividing the system into functional modules and assigning team responsibilities.
* Supporting the design and simulation of the digital circuits in Proteus.
* Coordinating the physical assembly and integration of the modules.
* Testing communication between the registers, bus, memory, ALU, and control unit.
* Troubleshooting wiring, timing, and control-signal problems.
* Preparing the final demonstration and technical presentation.

## ⚙️ Computer Architecture

The completed computer consists of the following main modules:

* **Clock Module:** Generates manual and automatic clock pulses for synchronized operation.
* **8-Bit Data Bus:** Transfers data and instructions between the computer modules.
* **A and B Registers:** Temporarily store operands for arithmetic and logic operations.
* **Arithmetic Logic Unit:** Performs binary addition and subtraction.
* **Random-Access Memory:** Stores program instructions and temporary data.
* **Program Counter:** Tracks and outputs the address of the next instruction.
* **Instruction Register:** Holds the current instruction during execution.
* **Control Unit:** Generates the control signals required for each instruction cycle.
* **Output Register:** Stores and displays the result produced by the computer.
* **EEPROM-Based Logic:** Stores the microcode used to control instruction execution.

## 🛠️ Tools & Build Process

* **Circuit Design and Simulation:** Proteus Design Suite 8.
* **Hardware Construction:** Breadboards, discrete logic ICs, EEPROMs, LEDs, resistors, capacitors, and manual wiring.
* **Testing:** Individual modules were tested separately before being connected to the shared data bus.
* **System Integration:** The complete instruction cycle was verified through program execution and output testing.
